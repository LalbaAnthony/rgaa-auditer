Notes

  • Search: every word must match, in the number, title, topic, page, finding, selectors, faulty code or expected correction.
  • Entries marked as done stay in place until the list is refreshed (filter or view change, reload); they then move to the end of their group, and fully done groups move to the end of the list.
  • The grouped action applies to every non-compliant and to-verify entry of the criterion, on all pages, whatever the filters.
  • Copy prompt: Markdown prompt for a coding agent, with the project context (Prompt settings), the audit data and instructions. The all-pages prompt groups pages sharing the same faulty code and leaves out entries marked as done.
  • Done states are stored in this browser for each audited page (page URL + page audit timestamp): pages added to the report later keep the progress of the others. Opened from disk, every local copy of this viewer shares the same storage.

Prompt settings

Added to every copied prompt under “Project context”. Saved automatically in this browser. Leave empty to omit the section.

Purge all stored data?

This deletes the memorized audit, the done states of every audit and the preferences (theme, prompt context) stored by this viewer in this browser. It cannot be undone.
